About The Project

What is AI Consent Guardian?

AI Consent Guardian is an AI-powered privacy analysis application built to give everyday internet users clarity before clicking "I Agree". It parses dense legal documents and extracts data collection practices, security risks, user permissions, and red flags into simple, actionable visual dashboards.

1. Artificial Intelligence

Leverages cutting-edge Large Language Models (Google Gemini API) for zero-shot legal text analysis, entity extraction, sentiment scoring, and natural language question answering.

2. Cybersecurity & Privacy

Promotes user consent awareness and data sovereignty. It flags hidden telemetry, aggressive ad tracking, indefinite data retention, and non-consensual third-party broker sharing.

3. Internet Programming

Engineered with Python & Flask, asynchronous Fetch API communications, secure temporary document processing with PyPDF, and a high-contrast responsive glassmorphism interface.
